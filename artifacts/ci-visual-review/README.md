# CI Visual Review Example

These screenshots are a committed example of the review bundle generated by:

```sh
npm run demo:allow-delay
```

Playwright injects the amber outlines and captions only while recording the
demo. They are not part of the packaged extension.

The GitHub Actions run also uploads a short WebM walkthrough, an interactive
trace, and any visual-regression diffs as a seven-day artifact. The video and
trace are intentionally not committed to Git history.
